# Controle Financeiro

Projeto desenvolvido como desafio prático do curso no SENAC.

O objetivo do desafio era criar toda a lógica em JavaScript para um sistema simples de controle financeiro, utilizando um HTML e CSS previamente disponibilizados pelo professor.

---

🔗 **Projeto no ar:** https://wsfraga.github.io/controle-financeiro/

## Preview

```bash
(./img/preview.png)
```

---

## Funcionalidades

* Adicionar novos gastos
* Atualizar quantidade de gastos automaticamente
* Calcular total dos gastos em tempo real
* Remover gastos da lista
* Formatação automática de moeda em Real (R$)
* Interface responsiva

---

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

---

## Aprendizados

Durante o desenvolvimento desse projeto, pratiquei:

* Manipulação do DOM
* Eventos com `addEventListener`
* Criação dinâmica de elementos
* Uso de funções para separar responsabilidades
* Manipulação de strings e números
* Uso de `querySelector` e `querySelectorAll`
* Atualização dinâmica da interface
* Event Delegation para remoção de itens
* Formatação de moeda utilizando `Intl.NumberFormat`
